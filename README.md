# API Calculator

API-калькулятор, разработанный на Python с использованием FastAPI.

## Реализованные операции

- сложение;
- вычитание;
- умножение;
- деление;
- возведение в степень;
- обработка ошибки деления на ноль.

## Используемые технологии

- Python 3.13;
- FastAPI;
- Uvicorn;
- Docker;
- GitHub Actions.

## Локальный запуск

```powershell
py -3.13 -m uvicorn main:app --reload
```

## Docker

Сборка образа выполняется по `Dockerfile`:

```powershell
docker build -t calculator-api .
```

Запуск контейнера:

```powershell
docker run --rm -p 8000:8000 calculator-api
```

## CI Pipeline

При каждом push в ветку `main` автоматически запускается GitHub Actions workflow.

Сборка приложения в CI не разбивается на отдельную установку Python и зависимостей. GitHub Actions запускает `docker build`, а все действия по подготовке среды выполняются самим `Dockerfile`: берётся базовый образ Python, устанавливаются зависимости, копируется приложение и задаётся команда запуска.

Для каждой CI-сборки формируется версия вида `1.0.<номер_запуска>` через `github.run_number`.

## Security scanning

В CI-пайплайн интегрированы следующие инструменты:

- **Semgrep** — статический анализ исходного кода и файлов конфигурации;
- **Trivy** — поиск известных уязвимостей в Docker-образе, системных пакетах и библиотеках;
- **Syft** — формирование SBOM, то есть перечня компонентов и версий внутри Docker-образа;
- **Grype** — проверка созданного SBOM на известные уязвимости;
- **Gitleaks** — поиск случайно опубликованных секретов, токенов, паролей и ключей в Git-репозитории и его истории;
- **Checkov** — анализ Dockerfile и CI/CD-конфигурации на небезопасные настройки и ошибки конфигурации.

Проверки запускаются автоматически при push в `main`. Их результаты доступны на вкладке **Actions** соответствующего запуска `Calculator CI Security`.

Подробный разбор результатов находится в файле `SECURITY_ANALYSIS.md`.
