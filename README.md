# API Calculator

API-калькулятор, разработанный на Python с использованием FastAPI.

## Реализованные операции

- сложение;
- вычитание;
- умножение;
- деление;
- возведение в степень;
- обработка ошибки деления на ноль.

## Используемые технологии

- Python 3.13
- FastAPI
- Uvicorn
- Docker

## Локальный запуск

```powershell
py -3.13 -m uvicorn main:app --reload

## CI Pipeline

При каждом push в ветку main автоматически запускается GitHub Actions.
Пайплайн устанавливает зависимости, проверяет приложение и собирает Docker-образ новой версии.

## Security scanning

В CI-пайплайн интегрированы:

- Semgrep — статический анализ исходного кода;
- Trivy — анализ Docker-образа и зависимостей.

Проверки автоматически запускаются при каждом push в ветку main.
